# ADR-005 — Sanitization and allowlist baseline

**Status:** Proposed; pending domain-owner and human review
**Date:** 2026-10-26
**Context:** Constitutional grilling G1=B, G2=C, G3=C, G4=C, G5=A, G6=C, G7=B, G8=D; v2.0.0 draft amendment.

## Decision
Require format-aware sanitization, typed schemas, component/action allowlists, URL/network restrictions and negative tests. Sandboxing is optional by risk, not prohibited. Existing sandbox must not be removed without a reviewed security change.

## Consequences
The policy is documented but does not establish that runtime features, tests or approvals exist. Implementation requires a scoped spec, applicable gates, assigned owner review and evidence at the exact SHA.

## Governance
Superseded by the Constitution if inconsistent. No merge or ratification is authorized by this proposed ADR.
